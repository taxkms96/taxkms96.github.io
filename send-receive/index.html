send-receive

send-receive 는 개인 PC 에서 쓰는 작은 프로그램('녹화 보내기')입니다. 내가 찍은 화면 녹화 파일을 내 구글 드라이브에 올리고, 그 링크를 내 Gmail 로 나에게 보냅니다.

  • 구글 드라이브: 이 프로그램이 만든 파일만 다룹니다(drive.file).
  • Gmail: 메일 보내기만 합니다(gmail.send). 받은편지함은 읽지 않습니다.
  • 모든 일은 사용자의 PC 안에서 일어나며, 따로 서버를 두지 않습니다.

개인정보처리방침 (Privacy Policy)

send-receive is a small personal desktop tool. It uploads the user's own screen recordings to the user's own Google Drive (drive.file — only files created by this app) and emails the link to the user's own Gmail address (gmail.send — send only). It runs entirely on the user's PC; there is no server. See the Privacy Policy.
