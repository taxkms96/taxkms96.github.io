send-receive 개인정보처리방침

시행일: 2026년 10월 27일

1. 다루는 정보

  • 구글 드라이브(drive.file): 이 프로그램이 올린 녹화 파일과 그 파일을 담는 '녹화 보내기' 폴더만 만들고 확인합니다. 다른 드라이브 파일은 보지 않습니다.
  • Gmail(gmail.send): 사용자 본인에게 드라이브 링크 메일 한 통을 보냅니다. 메일함을 읽거나 지우지 않습니다.
  • 계정 이메일 주소: 메일을 본인에게 보내기 위해 받는이 주소로만 씁니다.

2. 저장과 공유

  • 프로그램은 사용자의 PC 에서만 돌며 개발자에게 어떤 정보도 보내지 않습니다. 따로 서버가 없습니다.
  • 구글 허용 정보(토큰)는 사용자 PC 안에만 저장됩니다.
  • 어떤 정보도 제3자에게 팔거나 넘기지 않으며, 광고에 쓰지 않습니다.
  • Google API 에서 받은 정보의 사용과 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

3. 허용 끊기

언제든 Google 계정 › 서드 파티 연결에서 send-receive 의 허용을 지울 수 있습니다. PC 의 토큰 파일을 지워도 됩니다.

Privacy Policy (English)

Effective: October 27, 2026. send-receive runs only on the user's own PC and has no server. It uses Google Drive (drive.file) only to create and verify the recording files and the "녹화 보내기" folder it creates, and Gmail (gmail.send) only to send one email containing the Drive link to the user's own address. It does not read the mailbox or other Drive files. OAuth tokens are stored only on the user's PC. No data is sent to the developer, sold, shared with third parties, or used for advertising. send-receive's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time at myaccount.google.com/permissions. Contact: github.com/taxkms96.
